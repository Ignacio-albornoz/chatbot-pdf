1.​ Introducción 
 
 
 
01 
Objetivo 
▰​ Brindar una guía práctica y clara para el uso del Jenkins 
de Despliegue de BBVA, asegurando que los equipos de 
desarrollo puedan ejecutar sus despliegues siguiendo 
buenas prácticas y bajo el marco del flujo Git Flow 
02 
Acceso claro y 
controlado 
▰​ Este manual describe paso a paso el proceso para 
ejecutar despliegues en diferentes entornos, según la 
rama seleccionada 
03 
Gestión de Peticiones 
▰​ Se detalla el procedimiento para enviar correctamente la

1.1.​Descripción general 
Este manual tiene como objetivo guiar a los equipos de System en el uso del Jenkins de Despliegue, 
una herramienta diseñada para facilitar el paso a entornos de desarrollo, integración y producción de 
forma controlada y segura, siguiendo la estrategia de ramas Git Flow. 
A lo largo del documento se describen las reglas que rigen los despliegues, los accesos necesarios y el 
paso a paso para ejecutar correctamente cada tipo de despliegue, incluyendo los requerimientos 
específicos para ambientes críticos como producción.
